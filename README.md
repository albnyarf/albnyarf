## 🎯 Fokus Utama & Kegiatan Saat Ini

* **Sistem Tingkat Rendah & Sistem Operasi:** Mengeksplorasi algoritma C++, mekanika memori dan penjadwalan proses, serta cara kerja internal sistem operasi.
* **Jaringan Komputer & Linux:** Merancang skema *subnetting* IP, menyimulasikan topologi dan *routing* jaringan di **Cisco Packet Tracer**, serta menjalankan lingkungan Linux (*Ubuntu* & *Kali Linux*) di **VirtualBox**.
* **Basis Data, Web & Prototipe UI:** Bekerja dengan basis data SQL, membangun halaman web interaktif, dan merancang prototipe antarmuka di **Figma**.
* **Eksplorasi AI:** Mempelajari konsep kecerdasan buatan dan bagaimana alur kerja cerdas terhubung dengan rekayasa sistem inti.
